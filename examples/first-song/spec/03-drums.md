# ドラム
## 選択肢の例
- 基本8ビート: キック1・3拍、スネア2・4拍(バックビート)、ハイハット8分 → 安定してノれる
- 4つ打ち: キックを全拍に → ダンス寄りで推進力
- ハーフタイム: スネアを3拍目だけ → ゆったり重い
ベロシティ(音の強さ)を拍で変えると人間味が出る(表拍を強く、裏拍を弱く)。
