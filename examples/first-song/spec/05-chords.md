# コード楽器(ピアノ/パッド/ギターなど)
## 選択肢の例
- ブロック(和音を一度に): 厚みがあり、ロングトーンならパッドのような広がり
- アルペジオ(分散): 動きが出て、軽やか
- 転回形でつなぐ: 前のコードに近い音を選ぶと滑らか(動く音が少ない)
ベースと音域がぶつからないよう、中域(C3〜C5)に置く。
