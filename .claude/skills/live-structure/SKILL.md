---

AGENTS.md「構成の確認(必須)」と `docs/structure-template.md` に従う。**AI が自分で決めない**(スタイル②でも)。

1. `work/current.rb` と `work/structure.md`(あれば)を読み、いまのセクションと進行を把握する。`uv run scripts/check_structure.py` を実行して、足りない所(未確認・空欄・変化不足)を確認する。
2. 聞く。**セクションごとに1つずつ**(まとめて長い質問をしない):
   - 長さ(小節)・雰囲気/役割・鳴らす楽器・つなぎ(riser / 無音 / フィル / クラッシュ / なし)。
   - コード進行は、狙い(安定・開放・緊張・浮遊・締め・暗い)が違う **5案**を、ローマ数字+現在のキーのコード名+一言の理由で出し、おすすめを1つ添える(`docs/structure-template.md` の候補を使う)。前後のセクションと進行が変わるように提案する。ユーザーが自分の案を言ったら、それを優先する。
3. ユーザーの答えを `work/structure.md` の表に書く。**ユーザーが了承した行にだけ `✔ 日付` を付ける**(AI が勝手に付けない)。迷っている行は「確認」を空にしておく。
4. `uv run scripts/check_structure.py` で検証し、結果(警告・誤り)をそのまま伝える。完成前は `--final`。誤りが残る間は、完成扱いにしない。
5. 決まった構成を `work/notes.md` に1行足す。ユーザーが選んだ進行は、`learning-log` スキルで学習ログに追記する(なぜその進行で、そう聞こえるのか)。
6. スタイル②では、決まった構成に沿って `current.rb` を書く(進行・セクションを AI が勝手に変えない。変えたいときは聞く)。スタイル①では、決まった構成を、ユーザーがコードにする。
