**追記するとき**(ユーザーが案を採用した次の応答までに。最終レビューでは、残りをまとめて)
1. `docs/learning-log.md` を読み、最新のエントリ番号(L0xx)と、索引(タグ)を確認する。
2. 採用した案を、冒頭のテンプレートの書式で1エントリ追記する(番号は連番)。
   - 見出し `### L0xx <短い題>`、タグの行(`タグ: #日本語名 #English-name …`)、日付・曲・ファイル(`songs/…` か `work/proposals/…`)。
   - **選んだ案**と、**選ばなかった案との違い**(1行)。
   - **コード**(該当部分の抜粋、数行)。
   - **理論上の意味**(度数・コード機能・リズムの位置・音域・倍音・帯域など。なぜそう聞こえるか)と**数値**(`amp`・`cutoff`・`sleep`・測った値)。聴かないと言えないことは「未確認」。
   - **聴きどころ**(何秒付近・何を聴くか)と、**試す課題**を1つ。
3. スタイル②では、AI が書いたコードに使った**技法・用語をすべて**、タグとして書く(ユーザーが選んでいない技法も含める)。
4. 新しいタグを使ったら、`uv run scripts/learning_log.py index` で索引を作り直す。基礎的な用語は `docs/glossary.md` にも1行足す。
5. 「学習ログに L0xx を追記しました」と1行で伝える。コミットはしない(ユーザーが頼んだときだけ)。

**振り返り・検索するとき**
- `uv run scripts/learning_log.py search <語>`(タグ・見出し・本文を検索し、該当エントリの見出しとタグを出す)。見つかったエントリを読み、要点を短く説明する。理論の辞書は `docs/music-theory.md`、技法は `docs/live-coding.md`。
