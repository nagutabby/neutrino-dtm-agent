---
name: coach-start
description: 新しい曲を始めるとき。目的・好み・使える時間を最大3問で確認し、projects/<song> と 00-concept の下書きを作る。
---

1. **最初の1問で「歌あり / インスト」を確認**(後から変えると作り直しになるため、曲作りの最初に決める)。その上で目的・好きな雰囲気/参考曲・使える時間を聞く(合計 **最大3問**、AskUserQuestion、雰囲気は形容詞でなく具体的な曲名を挙げ「〇〇(曲名/アーティスト)と同じ感じでよいですか?」と聞く。確信のある有名曲だけを挙げ、複製は提案しない)。
2. 曲名を決め、`scripts/new_song.sh <song>` を実行(先に `--dry-run` で確認)。
3. 回答を `spec/00-concept.md` に下書き(`vocal: true|false` を必ず記入。インスト曲は歌詞・ボーカル・歌メロの歌詞前提の説明を出さない)し、承認を取る(`approve.py`)。
4. `uv run scripts/spec_status.py <song>` で次に決める要素を案内する。
