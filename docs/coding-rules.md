# コードの書き方(コーディング規約)

拍子に基づいて直感的に書き、人が拡張しやすくするための規約。記法のヘルパーは [live-grid.rb](live-grid.rb)(`current.rb` の先頭に貼る)、使用例は [examples/grid_demo.rb](../examples/grid_demo.rb)、検証は `uv run scripts/live_check.py <file.rb>`(終了コード 0 / 1 警告 / 2 誤り)。AI が書くコード(スタイル②)も、ユーザーが書くコード(スタイル①)への提案も、この規約に合わせる。ユーザーが自分の書き方を持っているときは、そちらを優先する。

## 1. 拍とグリッド
- 既定は **1小節 = 4拍 = 16マス**(1マス = 16分音符 = 0.25拍)。拍の位置は 0 始まりの小数(0、0.5、0.75 …)。
- リズムは文字列で書く: `X` 強く(1.0)/ `x` ふつう(0.75)/ `o` 弱く(0.4)/ `1`〜`9` 強さを 0.1〜0.9 で細かく / `.` 休み / `-` 直前の音を1マス伸ばす。空白と `|` は見やすくするだけ(無視)。
  - 四つ打ち `"x... x... x... x..."`、裏拍 `".... ..x. .... ..x."`、伸ばす `"x--- ----"`。
- マスの数は **1小節のマス数の倍数**(既定 16 マス。32 マス = 2小節)。複数小節は書き並べる(`|` で小節を区切ると読みやすい)。
- **付点音符**: 付点8分 = 0.75拍 = 3マス(`x--`)、付点4分 = 6マス(`x-----`)。既定のグリッドでそのまま書ける。
- **解像度と拍子**(1曲で1つに固定。`use_bpm` の次に1回だけ書く):
  - `grid_res N` = 1拍あたりのマス数(既定 4 = 16分音符)。2 = 8分音符 / 3 = 8分3連 / 6 = 16分3連。
  - `grid_meter N` = 1小節の拍数(既定 4)。1小節のマス数 = `grid_res` × `grid_meter`。
  - 例: 3/4 = `grid_meter 3`(12マス)/ 5/4 = `grid_meter 5`(20マス)/ 6/8 = `grid_res 2` + `grid_meter 3`(8分音符6つ)/ 4/4 の3連符 = `grid_res 3`(12マス)。デモは [examples/grid_demo_34.rb](../examples/grid_demo_34.rb)。
  - スウィング(裏拍を遅らせる)と、1曲の中での拍子・解像度の混在は未対応。違う拍子は別の曲・別ファイルにする。

## 2. ステムごとの記法
| ステム | 記法 | ヘルパー |
|---|---|---|
| キック・スネア・ハイハット・クラップ | グリッド | `grid_play` |
| ベース | グリッド(リズム)+ 進行(音程)。進行の根音を鳴らす(種類は読まない。根音だけの進行でよい) | `grid_play ..., on: 進行` |
| コード | グリッド(刻む位置)+ 進行。`chord: true` でコード全体 | `grid_play ..., on: 進行, chord: true` |
| ボーカルチョップ | グリッド(鳴らす位置)+ `from:`(元 wav の拍位置)。元の wav は加工しない | `grid_chop` |
| メロディ・リード | `[拍の位置, 音名, 長さ]` の並び(`sleep` の足し算を書かない)。休符は書かない | (規約のみ。ヘルパーは未実装) |
| アルペジオ | グリッド + コードトーンの番号(`0 1 2 1`)。進行を変えても追従 | (規約のみ) |
| FX・ライザー・クラッシュ | セクションの境目に1行で指定(開始小節・小節数) | (規約のみ) |

### ヘルパー関数の一覧(`docs/live-grid.rb`。どれもパターン・指定した長さぶん `sleep` する)
| 関数 | 使いどころ |
|---|---|
| `grid_play voice, pattern, on:, chord:, steps:, fold:, note:` | 音を鳴らす。`on:` 進行の根音(`chord: true` でコード。コードには進行に種類が要る)/ `steps:` 根音に足す半音数の並び / `fold:` 音域を12半音に収める |
| `grid_chop clip, pattern, from:, base:` | 元の wav の切り貼り。`from: :same` は鳴らす位置と同じ元の位置を使う(`base:` で拍ぶんずらす) |
| `grid_roll voice, 回数, 拍数, amp0:, amp_step:, rate0:, rate_step:` | ロール・連打(だんだん強く・速く) |
| `grid_each pattern do \|位置, 長さ, 強さ, 文字\| … end` | 音ごとに自分で書く(複雑な音色・FX・アクセントの計算用) |
| `grid_ticks 拍数, 回数 do \|k\| … end` | 等間隔に n 回(`cutoff` をなめらかに動かすなど) |
| `grid_rest 拍数` / `grid_fold n, lo` | 休み / 音を lo〜lo+11 に収める |
- **立ち上がり・立ち下がり**(`grid_voice` と `grid_chop` のオプション。数字(拍)でも書ける):
  - `attack:` = `:instant`(0)/ `:fast`(0.01)/ `:mid`(0.1)/ `:slow`(0.4)、`release:` = `:cut`(0.03)/ `:short`(0.15)/ `:mid`(0.4)/ `:long`(1.0)。
  - `env:` で型を一括指定: `:pluck`(急に立ち上がって短く切る)/ `:stab`(急・やや短い。Future Bass のシンセ)/ `:pad`(ゆっくり立ち上がって長く残る)/ `:swell`(だんだん大きくなって急に切る)。`env:` と `attack:` / `release:` を両方書いたら後者が優先。
  - 知らない言葉は実行時エラー、`live_check.py` は誤りにする。
- シンセの音の長さは、パターンの長さから決まる: `sustain` = マス数 × 1マスの長さ × `gate`(既定 1.0)− `cut`(既定 0)。`grid_voice` の中に書く。
- 実例: [examples/grid_demo.rb](../examples/grid_demo.rb)(4/4)、[examples/grid_demo_34.rb](../examples/grid_demo_34.rb)(3/4)。

## 3. 変数と名前
- リズム・音・進行を **別々の変数** にして、`live_loop` の中では参照するだけにする。定義はファイルの先頭にまとめる。
  - リズム: 形が分かる名前(`four`、`offbeat`、`stab`)/ 音: `grid_voice`(楽器_性格。`kick`、`bass`、`pad`)/ 進行: `grid_prog`(セクション_p。`verse_p`、`drop_p`。種類は省略可。ベース用は `grid_prog :eb1, :cb1`、コード用は `[:eb3, :minor7]`)/ 元の wav: `grid_clip`(拍数も渡す)。
- `define` の名前は **`grid_` で始める**。Sonic Pi のコア API(`at` など)と衝突すると実行時エラーになり、`live_check.py` では検出できない。
- 同じリズムを別の音に、同じ音を別のリズムに当てられるようにする(音だけ・リズムだけを差し替えるのが1行になる)。

## 4. 演算は必要なときだけ
- グリッドの連結・間引き・ずらし(`+`、`.mask`、`.shift`、`.accent`、`.bar`)は、**ユーザーが求めたとき、または同じ変数を3回以上少しずつ変えて書いているときだけ** 使う。最初は変数への名前付けだけで済ませる。
- 使った場合は、使った理由と読み方を添える。`live_check.py` は警告する。

## 5. テンポと待ち
- `use_bpm` は先頭の **1箇所** だけ。
- `grid_play` と `grid_chop` は、パターンの長さぶん自分で `sleep` する。この2つを呼ぶ `live_loop` に `sleep` を足さない(二重に待つ)。小節数の違う `live_loop` を並べるときは、長さを揃える(1小節のパターンを繰り返すか、4小節ぶん書く)。

## 6. ボーカルチョップ
- `grid_clip` に wav のパスと **元の拍数** を渡す(NEUTRINO の wav は、頭の無音を捨てた拍数)。
- `from:` は音の数と同じ個数(`x X o` の数)。省略すると元の先頭から順に続けて進む。ヘルパーは元の wav を加工せず、`start:` / `finish:` で切り出す(切り口のプチ音を防ぐ `attack: 0.008` `release: 0.06` が既定)。
- 同じ位置を続けて使うとスタッター、別の位置へ飛ぶとジャンプ。

## 7. ヘルパー関数の拡張
- `docs/live-grid.rb` のヘルパー関数は、曲に必要なら **拡張してよい**(関数・オプション・記号の追加、既存の挙動の変更)。
- ただし **変更する前に、必ずユーザーに確認する**。何を足すか(または変えるか)、理由、既存の曲・検証への影響を示し、了承を得てから書き換える。確認なしに変更しない(スタイル①②どちらも)。
- 拡張したら、`grid_` で始まる名前にし、`docs/live-grid.rb` の冒頭コメントと、この規約、`scripts/live_check.py`(必要なら)とテストを揃えて更新し、実機で動作を確かめる。
- ヘルパーを増やす前に、既存の関数と `grid_each`(音ごとに自分で書く)で書けないかを考える。

## 8. 検証
`uv run scripts/live_check.py <file.rb>`(Sonic Pi の API の検査とグリッド記法の規約の検査を一度に行う)を通してから渡す。
- 誤り: マス数が 1小節のマス数の倍数でない / `grid_res` `grid_meter` が正の整数でない / `from:` の個数が音の数と違う / `from:` が元の wav をはみ出す。
- 警告: `define` が `grid_` で始まらない / `grid_play` と `sleep` の二重待ち / `use_bpm` が無い・複数 / `grid_res` `grid_meter` が複数の値 / 演算の使用。
