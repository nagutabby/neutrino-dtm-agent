# 用語集(平易版)

- **キー**: 曲の中心になる音と音階。C(ハ長調)は白鍵だけ。
- **長調 / 短調**: 明るい響き / 切ない響きの音階。
- **コード**: 同時に鳴らす3つ以上の音のまとまり(和音)。
- **コード進行**: コードの並び。曲の「場面転換」の設計図。
- **テンポ(BPM)**: 1分間の拍の数。大きいほど速い。
- **小節 / 拍**: 時間の区切り。4/4拍子は1小節に4拍。
- **表拍 / 裏拍**: 拍の頭 / 拍と拍の間。裏拍を強調するとノリが出る。
- **バックビート**: 2・4拍目(スネア)を強調するリズム。
- **ベロシティ**: 音の強さ(1〜127)。
- **音域**: 出す音の低〜高の範囲。
- **ルート音**: コードの土台になる音(Cコードなら C)。
- **休符**: 音を出さない時間。歌では息継ぎにもなる。
- **モチーフ**: 繰り返す短いメロディの型。
- **ステム(stem)**: トラック単体の音声ファイル。
- **ラウドネス(LUFS)**: 人が感じる音量。配信は -14 LUFS 前後が目安。
- **度数 / 音程**: 音と音の距離。主音を1度として数える(C メジャーの E は3度)。
- **トニック / サブドミナント / ドミナント**: コードの機能。安定 / 動き出し / 緊張(T / SD / D)。
- **解決 / カデンツ(終止)**: 緊張(V)から安定(I)へ戻ること。区切りの感じを作る。
- **ローマ数字表記**: キーに依存せずコードを表す記法(C メジャーの G は V)。
- **ダイアトニックコード**: そのキーの音階の音だけでできたコード。
- **コードトーン / 非和声音**: コードの構成音 / それ以外の音(経過音など)。
- **転回形**: コードの最低音を入れ替えた形。コード間を滑らかに繋ぐ。
- **ペンタトニック**: 5音の音階。外れにくく初心者のメロ向き。
- **平行調**: 同じ7音を使う長調と短調(C と Am)。
- **シンコペーション**: 拍の裏から入って次の表拍を食う、ノリのあるリズム。
- **フォルマント**: 声の「あ・い・う・え・お」を決める共鳴の山(周波数帯)。母音ごとに位置が違う。
- **ボコーダー**: 声の響きの形(フォルマント)をシンセ音に載せて、機械的に歌わせる効果。
- **母音 / 子音**: 伸ばせる音(a i u e o)/ 息や口の動きで作る短い音(k s t m など)。響き重視なら母音が主役、子音がリズムを作る。
