# 用語集(平易版)

- **キー**: 曲の中心になる音と音階。C(ハ長調)は白鍵だけ。
- **長調 / 短調**: 明るい響き / 切ない響きの音階。
- **コード**: 同時に鳴らす3つ以上の音のまとまり(和音)。
- **コード進行**: コードの並び。曲の「場面転換」の設計図。
- **テンポ(BPM)**: 1分間の拍の数。大きいほど速い。
- **小節 / 拍**: 時間の区切り。4/4拍子は1小節に4拍。
- **表拍 / 裏拍**: 拍の頭 / 拍と拍の間。裏拍を強調するとノリが出る。
- **バックビート**: 2・4拍目(スネア)を強調するリズム。
- **ベロシティ**: 音の強さ(1〜127)。
- **音域**: 出す音の低〜高の範囲。
- **ルート音**: コードの土台になる音(Cコードなら C)。
- **休符**: 音を出さない時間。歌では息継ぎにもなる。
- **モチーフ**: 繰り返す短いメロディの型。
- **StyleShift**: NEUTRINO で歌い方(声の高さの傾向)をずらす設定。
- **Transpose**: 出力の音高を半音単位でずらす設定。
- **ステム(stem)**: トラック単体の音声ファイル。
- **ラウドネス(LUFS)**: 人が感じる音量。配信は -14 LUFS 前後が目安。
