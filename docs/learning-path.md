# 学習ロードマップ(ライブコーディング版)

| Level | 目標 | ステム |
|---|---|---|
| 1 | 4つのコード+ビートで8小節ループ | Drums, Bass, Chords |
| 2 | 旋律と展開(`tick` / `choose` / `if` でループを変化) | + Melody, 装飾 |
| 3 | 構成(イントロ→サビ)とミックス(`amp` / `pan` / FX) | + セクション切替、最終レビュー |

## 練習課題
- `cutoff` を 70 / 90 / 110 にして聴き比べる
- キックとベースの拍を揃える/ずらして「タイトさ」を聴き比べる
- `reverb` の `room` と `mix` を変える
- コード進行の順番を入れ替える
