# 学習ロードマップ

| Level | 目標 | トラック |
|---|---|---|
| 1 | 4コード+歌えるメロディの曲(長調・音域1オクターブ内・8小節) | Drums, Bass, Chords, Melody(+Vocal) |
| 2 | Aメロ/サビの対比、装飾トラック | + カウンターメロ/アルペジオ |
| 3 | ブリッジ、StyleShift・モデル選び、ミックス | + ミックス調整 |

## 練習課題
- 同じメロディを3つのテンポ(80/100/120)で聴き比べる
- コード進行を `C-G-Am-F` と `Am-F-C-G` で入れ替えて聴き比べる
- `ab_render.sh` で StyleShift 0/2/-2 の歌い方の違いを聴く
- ベースの位置をキックと揃える/ずらすで「タイトさ」の違いを聴く
