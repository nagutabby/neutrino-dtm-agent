# spec 選択肢カタログ(spec-propose 専用。spec には写さない)

最大3案を聴感の効果つきで提示する。ユーザー案を優先。

## 00-concept
- 明るい: 長調・速め・短い音で弾む / 切ない: 短調・遅め・長い音 / 力強い: 低音強め・バックビート強調

## 01-structure
- key: C(白鍵のみ)。歌いやすさで後から移調
- tempo: 80〜100 ゆったり / 110〜130 ポップ / 140〜 速い。遅いほど歌詞の音数は減る
- 構成: まずサビ8小節 → 慣れたら A→B→サビ

## 02-harmony(C メジャー)
- C→G→Am→F: 明るい定番 / Am→F→C→G: 切なさから前進 / C→Am→F→G: 懐かしい王道
- 始まりと終わりを主和音(C)に置くと「帰ってきた」感

## 03-drums
- 基本8ビート: キック1・3、スネア2・4、ハイハット8分(安定) / 4つ打ち: キック全拍(ダンス寄り) / ハーフタイム: スネア3拍目のみ(重い)
- ベロシティは表拍強・裏拍弱で人間味

## 04-bass
- ルート4分(土台) / ルート8分(推進力。キックと同位置で一体感) / 経過音あり(なめらか)
- 音域 C1〜C3(C1未満は聞こえにくい)

## 05-chords
- block(厚み。ロングトーンでパッド的) / arpeggio(動き・軽やか) / 転回形でつなぐ(動く音が少なく滑らか)
- 音域 C3〜C5(ベースと被らない)

## 06-melody(ユーザーが先に書く → AI は改善案2つ)
- 音域は1オクターブ程度(C4〜C5)/ 強拍にコード構成音 / 同リズム反復+最後だけ変える(モチーフ)/ 切れ目に休符(息継ぎ)

## 07-lyrics
- 1音符1音節。ひらがな・スペース区切り(拗音は1音節: きゃ)。音符数と不一致なら lyrics_inject.py がエラー
- アクセントのある音節は強拍へ

## 08-vocal
- model: MERROW/NAKUMO/REINA/RUNO/SOMA(ab_render.sh で聴き比べ)
- style_shift: 表情(声の高さの傾向) / transpose: 半音単位でずらす

## 09-mix
- 主役は vocal(歌なしは melody)、伴奏は少し下げる。歌なしの曲はその曲の spec だけ depends_on から 08-vocal を外してよい
- 低音は中央、コード楽器は少し左右 / loudness 目安 -14 LUFS
- approved 後に mix_tracks.sh が levels_db(dB)・pan(-1左〜+1右)・loudness_lufs を反映
