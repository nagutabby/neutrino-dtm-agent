# ボーカルと伴奏を調和させる / インストだけでも成立させる

歌ありの曲の参照用(AGENTS.md「ボーカルとの調和」)。歌声は NEUTRINO、伴奏は SuperCollider で別々に作るため、そのまま重ねると「歌だけ浮く」「歌を抜くと曲が空」になりやすい。次の2軸で防ぐ。

## 1. インストだけで曲として成立させる(必須)
歌は「乗せるもの」で、曲の骨格は伴奏側が持つ。
- **主旋律をボーカルだけに持たせない**。ボーカルが歌う区間で、ユーザーが指示したトラックのうち旋律を担えるもの(リード・メロディ・コードの最上声など)が、ボーカルの旋律線を**オクターブ違い・簡略化・合いの手**で追う/受ける。歌がない区間(イントロ・間奏・アウトロ)はそのトラックが主役になる。
- **フック(覚えやすい短い旋律)を伴奏側にも置く**。ボーカル休符の位置(`07-lyrics`/`08-vocal` の息継ぎ)に伴奏の合いの手を入れ、歌と交互に埋める(コール&レスポンス)。
- **区間ごとの密度**: 全区間に「リズム + 低域 + 旋律または和声」のうち2要素以上が鳴ること。ボーカル抜きでも山と谷(`mix-review-viewpoints.md` #1・#2)が残ること。
- **指示されたトラックだけ**で組む。足りない要素(例: 旋律を担えるトラックが無い)があっても AI はトラックを足さない。`spec` の `usage`/`sections`/`params` の範囲で配置を工夫し、足りなければ最終報告(`step` は都度)で「旋律役のトラックがない」と事実だけ伝えて、ユーザーに判断を仰ぐ。
- **検証**: ボーカルを除いたミックスを作って確認する。`scripts/mix_tracks.sh <song> <step> exclude=vocal` → `mix/step<N>_inst_vN.wav`。`mix-review` はこのインスト版も対象にし、「ボーカルなしで曲として成立するか」を見る。再生コマンドを通常ミックスと並べて提示する。

## 2. ボーカルを伴奏になじませる(歌ありの標準処理)
音を聴けないので数値で作り、聴感はユーザーに渡す。
- **拍・キーの一致**: ボーカルの MusicXML は伴奏と同じテンポ・調。NEUTRINO 出力の前後1小節の休符(仕様)ぶんのずれを、ミックスの開始位置で合わせる。歌いやすい音域に寄せるときは楽譜側で移調し、伴奏も同じ調にそろえる。
- **周波数の住み分け**: ボーカルの中心帯域(目安 200〜4000 Hz)で、旋律系・コード系の cutoff を下げるか音量を -3〜-6 dB。低域(〜150 Hz)はキック/ベースに任せ、ボーカルは HPF 80〜120 Hz。
- **ダッキング**: ボーカルが歌う間だけ旋律系・パッドを -2〜-4 dB(サイドチェイン的)。ミックスで区間ごとに levels を変えるか、SuperCollider 側でエンベロープを掛ける。
- **空間をそろえる**: ボーカルにも伴奏と同種のリバーブ(同じ部屋感・残響 0.8〜1.5 秒、wet 10〜25%)を掛ける。乾いた歌 + 湿った伴奏、またはその逆は「別録り」に聞こえる。
- **音色の質感をそろえる**: 伴奏に歪み・ローファイ加工があるなら、ボーカルにも軽く(サチュレーション・帯域制限)かけて質感の距離を縮める。
- **ボーカルが主役の区間で、伴奏の音量・密度を下げる**(`mix-review-viewpoints.md` #10)。

## 3. 歌声をシンセ/ボコーダーで「楽器の音」に変換して溶かす
素の歌声が浮くときの手段。**ユーザーの指示、またはミックスレビューの「ボーカルが浮く」指摘への対応(spec の差分案)として使う**。AI は曲の最初に候補として出さない。
- **ボコーダー**(SuperCollider の `Vocoder`/チャンネルボコーダーを `projects/<song>/synth/synthdefs.scd` に書く): モジュレーター = NEUTRINO のボーカル wav、キャリア = その曲専用のシンセ(ノコギリ波・パッド等。コード/旋律の MIDI で鳴らす)。ボーカルのリズムと母音が、伴奏と同じ音程・音色の「歌う楽器」になる。帯域数 16〜32、キャリアはコードトーンに合わせる。
- **重ね方**: 素の歌 + ボコーダー声を 1:0.3〜0.5 で重ねる(歌詞の明瞭さを保ちつつ溶かす)。または特定区間(サビ・ドロップ)だけ全面ボコーダー。
- **ピッチ/フォルマントの加工**: 歌のオクターブ下/上を薄く重ねる、FormantShift 0.85〜0.9(低く太く)。キー補正の強い「機械的な声」にも寄せられる。
- **シンセに歌わせる**: ボーカルの旋律(MusicXML/MIDI)を、伴奏側のリードにも同じ音で弾かせて、声とシンセをユニゾンにする(これは MIDI 側の処理で、音声は使わない)。
- 処理は DSP(SuperCollider / ffmpeg)で行う。出力は `stems/NN_<track>_vN.wav`(例 `11_vocoder_v1.wav`)に置き、spec は `10-` 以降で足す(ユーザーの了承がある場合のみ。`auto` の差分案では decisions に理由を残す)。`patches.py check` を通す。
