# 歌ものに最低限必要な理論

1. **音階とキー**: C メジャーは C D E F G A B。歌メロはまずこの7音だけで作る。
2. **ダイアトニックコード(Cメジャー)**: C, Dm, Em, F, G, Am。C・F・G が主要、Am は切なさ。
3. **メロディの作り方**: 強拍にコード構成音(Cなら C/E/G)、弱拍は経過音。短いモチーフを繰り返し、最後だけ変える。
4. **歌詞と音節**: 1音符に1音節。言葉の強い音節を強拍に。音数はテンポとフレーズ長で決まる。
5. **構成**: 8小節単位が分かりやすい。まず「サビ8小節」から。

より深い理論(度数・機能和声・終止・声部連結・メロ理論・緊張曲線)は `docs/music-theory.md`。エージェントが「なぜ」を説明するときの辞書。
