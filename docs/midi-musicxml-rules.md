# NEUTRINO 向け MIDI / MusicXML の制約

- 歌声パートは**単旋律**(同時に鳴る音なし)、**1音符1音節**、**歌詞必須**
- 休符で息継ぎ(4小節以上休符なしは警告)
- 音域の目安 C3〜C5、幅は1オクターブ+α(モデル・声質で調整)
- 極端に短い音(32分音符未満)は避ける
- MusicXML は**1パート**、テンポ指定あり、和音(`<chord/>`)なし
- 歌詞は `lyrics_inject.py` で付与(ひらがな/カタカナ、拗音は1音節)
- 検査: `midi_validate.py` / `musicxml_validate.py`。違反は報告するだけで自動修正しない(初心者が理由を学べるようにする)
