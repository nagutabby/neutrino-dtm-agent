# AI 生成音楽にありがちな問題(ミックスレビューの観点)

本リポジトリのように「ルールとパターンから MIDI を組み、シンセで鳴らす」作り方で出やすい傾向。`mix-review` のレビュー担当(Haiku 5.5)が、この観点で最終ミックスを見る。数値の合否判定はしない(最終判断はユーザーの耳)。

| # | 傾向 | 出方 | 直し方 |
|---|---|---|---|
| 1 | ループの貼り合わせ | 1〜4小節のパターンを全区間でコピー。展開が感じられない | 区間ごとに素材・音域・密度を変える。4小節ごとに1〜2音を変える |
| 2 | 起伏がない | 全区間が同じ音量・同じ密度。山と谷がない | 谷の区間はトラックを半分以下に。山でトラックと音域を足す |
| 3 | 機械的な強弱とタイミング | ベロシティが固定。全音が 16 分グリッドぴったり | 強拍を強く、フレーズ頭尾で ±8〜12。ジャンルが許せば ±5〜15 tick のずれ |
| 4 | 帯域の偏り | 低・中低域に集中、高域が少なくこもる | cutoff・倍音の見直し、ハット追加、ベースの drive/decay を下げる |
| 5 | ステレオが狭い | 全パートが中央。広がりがない | `09-mix` の pan を ±0.3〜0.6 に振る(低音とキックは中央) |
| 6 | 間がない | 休符・息継ぎがなく、常に埋まる | フレーズ末に1拍以上の休符。break を作る |
| 7 | 導入と終わりが唐突 | 冒頭から全開。終わりが切れる | intro は少ないトラックで始める。`fade_in_sec` |
| 8 | 音域が狭い・山がない | 旋律が数音の中で動くだけ | 区間ごとに音域を上下させる |
| 9 | 無難な和声 | 同じ進行を最後まで。終止や転調の緊張がない | 区間の最後に別コード(借用和音・終止の変化)を入れる |
| 10 | 全パートが同時に主張 | 旋律系が重なり、主役が不明 | 主役を区間ごとに1つ決め、他は -3〜-6dB |
| 11 | ボーカルが浮く(歌ありのみ) | 歌だけ乾いている/質感が違う/伴奏と帯域がぶつかる。別録りに聞こえる | リバーブ・質感をそろえる、歌う間の旋律系を -3〜-6dB、HPF。改善しなければボコーダー声を 0.3〜0.5 で重ねる/区間だけ変換(`docs/vocal-blend.md`) |
| 12 | インストで成立しない(歌ありのみ) | ボーカルを抜くと旋律がない/区間が空。`step<N>_inst` で確認 | 旋律を担えるトラックに歌の旋律の追従・合いの手を持たせ、全区間で2要素以上を鳴らす |
| 13 | リズム型が単調 | 全音が拍頭・同じ音価・同じ強さ。メトロノームのように聞こえる(歌ありはボーカルが最大の原因になりやすい) | 下の「リズム型の数値」を超えるよう、音価・位置・強弱を spec に書く(食い・裏拍・付点・休符・アクセント) |

## リズム型の数値(#13。`uv run scripts/rhythm_stats.py <song> [track]` で測る)
トラックごとに、拍頭に乗る割合・8分裏・16分/3連の位置の割合・最頻の音価とその割合・ベロシティの種類数を出す。次に当てはまるトラックは「リズム型が単調」として挙げる(目安。ジャンルが意図する場合は `decisions` に理由を残して外す)。
- **拍頭 100%**、または**最頻の音価が 85% 以上**(4分一律・8分一律)。ただしキックの4つ打ちは意図的なので対象外にできる。その場合も他トラックで補えているか見る。
- **ベロシティが 1〜2種**、または幅が 10 未満(旋律・ボーカル・ハット類)。強拍で +8〜12、フレーズ頭尾で山を作る。
- **ボーカル**: 拍頭 70% 超、または 4分以外の音価が 20% 未満。アウフタクト(食い)・裏拍・付点・句末の伸ばしを入れる。
- **曲全体**: 全トラックが同じ格子(拍頭と8分)にしか音を置かない。1トラック以上が16分・3連・シンコペーションで格子をずらす。
- 区間ごとにも測る(同じ型の貼り合わせは #1)。ボーカルと伴奏で、アクセントの位置が完全に重なる/まったく噛み合わないのも挙げる。

## 直す手段(spec のパラメータ)
- 区間ごとの出番: 各トラック spec の `params.sections`(例 `[loop-c]`)。
- リズム型: 各トラック spec の `params.rhythm`(例 ボーカル `{pickup: 0.5, syncopation: 0.3, note_values: [8th, 16th, dotted-quarter], phrase_end: hold}`、ドラム `{ghost: 0.2, push: 16th}`)に、ほしい音価・食い・シンコペーションの割合を書いて再生成する。MIDI を直接直さない。
- ベロシティの抑揚: `params.accent`(`downbeat` / `offbeat` / `phrase_arc`)。`scripts/apply_accent.py` が MIDI 生成時に適用する(MIDI を直接直さない)。
- 導入の唐突さ: `09-mix` の `fade_in_sec`。ラウドネス正規化(loudnorm)が静かな導入を持ち上げるため、音源側でなくミックスで直す。
- 音量・パン: `09-mix` の `levels_db` / `pan`。

## 限界
レビュー担当は音を聴けない。数値で確かめられない点(9・10 など)は「聴いて確かめる箇所」としてユーザーに渡す。
