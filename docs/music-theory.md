# 音楽理論リファレンス(エージェントが「なぜ」を理論で説明するための辞書)

説明は **「聞こえ方 → 理論上の理由 → 数値(`explain_midi.py`) → 試せる課題」** の順。
理論用語は初出時に括弧で一言補い、定義は `docs/glossary.md` を案内する。初心者に一度に出す理論用語は最大2つ。

## 1. 音程と度数(音と音の距離)
| 音程 | 半音数 | 聞こえ方 | 使いどころ |
|---|---|---|---|
| 完全1度/8度 | 0/12 | 同じ音/オクターブ。完全に溶ける | ベースとメロの重ね、ルート |
| 長3度/短3度 | 4/3 | 明るい/切ない。長短を決める音程 | コードの性格、メロの目標音 |
| 完全4度/5度 | 5/7 | 安定・力強い | ルート移動、パワーコード |
| 長2度/短2度 | 2/1 | 滑らか / 強くぶつかる | 経過音。短2度の同時発音は濁る |
| 長7度/短7度 | 11/10 | 不安定で解決したい | 7thコードの色、サビ前の緊張 |
| 増4度(トライトーン) | 6 | 最も不安定 | G7 の B-F。C へ解決したくなる |

- 度数はキーの主音(トニック)を1とした順位。C メジャーなら C=1度, E=3度, G=5度。
- メロの跳躍は3度・4度・5度が歌いやすい。6度以上の跳躍は直後に逆方向へ戻すと自然(跳躍進行の後は順次進行で反行)。

## 2. 音階とモード
- メジャースケール: 全全半全全全半(C D E F G A B)。ナチュラルマイナー: 全半全全半全全(A B C D E F G)。
- 平行調: C メジャーと A マイナーは同じ7音(同じ調号)。切なくしたいが音域・歌詞は変えたくない時の第一候補。
- ペンタトニック(5音: C D E G A): 半音がなく外れにくい。初心者のメロ作りに最適。F と B(ぶつかりやすい音)を避けられる。
- 同主調(C メジャー ⇔ C マイナー)への借用: サビ前に Fm(IVm)を1小節入れると「切ない一瞬」が作れる(応用)。

## 3. ダイアトニックコードと機能和声
C メジャー: I=C, ii=Dm, iii=Em, IV=F, V=G, vi=Am, vii°=Bdim(ローマ数字。大文字=長三和音、小文字=短三和音)。

| 機能 | コード | 役割・聞こえ方 |
|---|---|---|
| トニック(T) | I, vi, (iii) | 安定・帰る場所。I は完全な安定、vi は切ない安定 |
| サブドミナント(SD) | IV, ii | 動き出し・広がり。T から離れる |
| ドミナント(D) | V, (vii°) | 緊張。T へ戻りたい力が最大 |

- 基本の流れ: **T → SD → D → T**(例 C-F-G-C)。D→T が「解決(カデンツ)」。
- 終止(区切りの感じ): 完全終止 V→I(完結)/ 半終止 …→V(続きが気になる、前半フレーズ向き)/ 偽終止 V→vi(期待を外して切なく)。
- よく使う進行と性格:
  - `I-V-vi-IV`(C-G-Am-F): 明るく切なさもある王道。
  - `vi-IV-I-V`(Am-F-C-G): 同じ4コードで vi 始まり。切なく入ってサビで開ける。
  - `IV-V-iii-vi`(F-G-Em-Am、王道進行): 切なく感情的。J-POP で多用。
  - `ii-V-I`(Dm-G-C): 最も強い解決。
- セカンダリードミナント: 次のコードの V を借りる(C→**E7**→Am)。進行に推進力。応用。
- 7th/テンション: 7th を足すと大人っぽく不安定、add9/sus はふんわり。初心者はまず三和音+必要なら G7 だけ。

## 4. 声部連結(ボイスリーディング)とコードの置き方
- 隣り合うコード間で**共通音は動かさず**、他の音は最短(半音/全音)で動かす → 滑らか。転回形(第1転回=3rd が最低音、第2転回=5th が最低音)を使う。
- 例: C(C-E-G)→F は、基本形のまま F-A-C に動かすと3音すべて動く。第2転回 C-F-A にすると共通音 C は動かず、E→F と G→A の半音・全音だけで済み、滑らかに繋がる。
- コードは C3〜C5 の中域、ベースは C1〜C3。**低音域で3度を重ねると濁る**(C2 付近で E と G を同時に鳴らさない)。
- 平行5度・平行8度(2声が同じ間隔で並んで動く)は声が溶けて独立感が消える。クラシックでは避けるが、ポップスのパワーコードでは意図的に使う。

## 5. リズムと拍子
- 4/4: 強-弱-中-弱。1拍目が最強、3拍目が次点。2・4拍はバックビート。
- シンコペーション: 拍の裏から入り次の表を食う。ノリ・推進力。スウィングは裏拍を後ろにずらす(三連 2:1)。
- 小節頭のベースとキックを揃える=タイト、少しずらす=グルーヴ。
- 休符は理論上も「フレーズの句読点」。歌は2〜4小節ごとにブレス。

## 6. メロディ理論
- **コードトーン(CT)/ 非和声音(NCT)**: 強拍は CT、弱拍は経過音・刺繍音・倚音(強拍に NCT を置き、次で CT へ解決)。
- 輪郭: 山型(上がって下がる)が歌いやすい。最高音は1フレーズに1回、サビの頂点に置くと印象が強まる。
- 反復と変化: モチーフ(2小節)を繰り返し、3回目で変形、4回目で終止形に。A-A'-B-A'' の考え方。
- 問いと答え(コール&レスポンス): 前半は半終止(上がって終わる)、後半は完全終止(主音へ戻る)。
- 主音・属音(5度)・3度に着地するとそれぞれ「完結 / 続く / 温かい」。
- 歌詞: 強い音節(アクセント)を強拍に。母音の長い語はロングトーンに。

## 7. 構成と緊張曲線
- 8小節=4+4(問い+答え)。Aメロ(抑え気味・低め)→Bメロ(上昇・ドミナント終わり)→サビ(最高音域・最大の音数/厚み)。
- 緊張は「音域↑・音数↑・ベロシティ↑・不協和↑」で上がり、解決で下がる。曲全体で山を設計する。
- 転調(+1 半音 or +2 半音)はラスサビの高揚に有効(Transpose と混同しない)。

## 8. 理論 → 数値 → 聞こえ方の対応(説明テンプレ)
| 理論的な事実 | 確認する数値(`explain_midi.py`) | 説明例 |
|---|---|---|
| キーと長短 | 推定キー、ノートの度数分布 | 「3度が E(長3度)なので明るい」 |
| コード機能 | 小節ごとのコード名 → ローマ数字へ変換 | 「4小節目の G(V)で緊張、次の C(I)で解決」 |
| 声部連結 | 隣接コードの共通音数・最大移動半音数 | 「C→Am は C と E が共通、移動は G→A の2半音だけ」 |
| メロとコードの関係 | 強拍が CT の割合、NCT の位置 | 「強拍の8割が CT なのでコードと馴染む」 |
| 音域・跳躍 | 最低〜最高、最大跳躍(半音数) | 「最大跳躍は5度(7半音)で歌いやすい」 |
| ぶつかり | 同時発音の短2度/長7度/トライトーン | 「ベース B と コード C が短2度でぶつかっている」 |

数値で取れない理論判断(機能・終止・解決感)は、**推定であることを明示**して根拠(コード名とローマ数字)を添える。ユーザーが選ぶ前に断定しない。
