# AI 生成音楽にありがちな問題とチェック

本リポジトリのように「ルールとパターンから MIDI を組み、シンセで鳴らす」作り方で出やすい傾向。`scripts/ai_check.py` が数値で目安を出す(最終判断はユーザーの耳)。

| # | 傾向 | 出方 | 自動チェック(目安) | 直し方 |
|---|---|---|---|---|
| 1 | ループの貼り合わせ | 1〜4小節のパターンを全区間でコピー。展開が感じられない | 同一小節が 70% 超、8秒区間の音色相関 > 0.85 | 区間ごとに素材・音域・密度を変える。4小節ごとに1〜2音を変える |
| 2 | 起伏がない | 全区間が同じ音量・同じ密度。山と谷がない | 4秒ごとの音量幅 < 6dB | 谷の区間はトラックを半分以下に。山でトラックと音域を足す |
| 3 | 機械的な強弱とタイミング | ベロシティが固定。全音が 16 分グリッドぴったり | 種類 ≤ 2 または標準偏差 < 3。全音がグリッド上(参考表示) | 強拍を強く、フレーズ頭尾で ±8〜12。ジャンルが許せば ±5〜15 tick のずれ |
| 4 | 帯域の偏り | 低・中低域に集中、高域が少なくこもる | 150〜500Hz > 40%、2kHz 以上 < 5% | cutoff・倍音の見直し、ハット追加、ベースの drive/decay を下げる |
| 5 | ステレオが狭い | 全パートが中央。広がりがない | 左右相関 > 0.95 | `09-mix` の pan を ±0.3〜0.5 に振る(低音とキックは中央) |
| 6 | 間がない | 休符・息継ぎがなく、常に埋まる | 休符がほぼ0 | フレーズ末に1拍以上の休符。break を作る |
| 7 | 導入と終わりが唐突 | 冒頭から全開。終わりが切れる | 冒頭2秒が大音量 | intro は少ないトラック、outro で薄くする |
| 8 | 音域が狭い・山がない | 旋律が数音の中で動くだけ | 音域 < 5 半音 | 区間ごとに音域を上下させる |
| 9 | 無難な和声 | 同じ進行を最後まで。終止や転調の緊張がない | (自動なし) | 区間の最後に別コード(借用和音・終止の変化)を入れる |
| 10 | 全パートが同時に主張 | 旋律系が重なり、主役が不明 | (自動なし。音量差で判断) | 主役を区間ごとに1つ決め、他は -3〜-6dB |

## 使うタイミング
- 全トラック生成と最終ミックスのあと(`auto` は最後にまとめて、`step` は累積ミックスごとに)に実行する。
- 警告が 0 件になるまで直す。Haiku 5.5 のサブエージェントに警告と関係する spec をレビューさせ、その見立てで `spec-revise` の流れ(spec の差分案 → version+1 → 該当トラックと下流のみ再生成)を繰り返す(最大 5 周。`step` は差分案ごとにユーザーの了承を得る)。詳細は `ai-check` スキル。
- 目安を外してもジャンルの特性なら問題ない(例: ハウスの 16 分グリッド固定)。その場合は理由を `decisions` に1行で残す。

## 限界
数値は耳の代わりにならない。9・10 は自動で測れないので、聴きどころ(何秒付近)を添えてユーザーに確認する。

## 直す手段(spec のパラメータ)
- 区間ごとの出番: 各トラック spec の `params.sections`(例 `[loop-c]`)。
- ベロシティの抑揚: `params.accent`(`downbeat` / `offbeat` / `phrase_arc`)。`scripts/apply_accent.py` が MIDI 生成時に適用する(MIDI を直接直さない)。
- 導入の唐突さ: `09-mix` の `fade_in_sec`。ラウドネス正規化(loudnorm)が静かな導入を持ち上げるため、音源側でなくミックスで直す。
- 音量・パン: `09-mix` の `levels_db` / `pan`。
