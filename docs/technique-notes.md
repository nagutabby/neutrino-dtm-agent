# 技術解説の辞書(提案に数値を添えるときに参照)

提案や解説に、**聞こえ方 → 裏付ける技術 → 数値**を添えるときの早見表。右端の **L0xx** は、実例を詳しく書いた `docs/learning-log.md` のエントリ(`uv run scripts/learning_log.py search <語>` で探せる)。理論の根拠は `docs/music-theory.md`、技法は `docs/live-coding.md`、用語は `docs/glossary.md`。

## ステム別
| ステム | 聞こえ方 | 裏付ける技術(数値) | 学習ログ |
|---|---|---|---|
| Drums | 勢い・ノリ | キック1・3拍/スネア2・4拍(バックビート)。ハーフタイムは、スネアを3拍目だけに置き体感テンポが半分。ハイハットは `amp` の表拍強/裏拍弱(例 `[0.45, 0.15, 0.3, 0.15]`)、4小節ごとの最後の拍だけ3連ロール | L001 L002 |
| Bass | 土台・安定・重み | コードのルートを F1〜E2(約 44〜83Hz)の sine で。キックの直後・間に置く(同じ位置に重ねない)。1オクターブ上の saw を軽く歪ませると、小さなスピーカーでも形が聞こえる。`release` を短くするとタイト | L003 L016 |
| Chords / パッド | 明るさ/切なさ・広がり | 長調/短調、C3〜C5 の中域。長い `release` = パッド的、短い = 軽やか。左右に振った `dsaw` を足すと広がる | L009 |
| Wobble(`supersaw`) | うねり・伸び | `cutoff` を LFO(正弦波)で開閉。中心 82・振れ幅 ±7・周期1拍。`detune` 0.3、`res` 0.2。キックの瞬間に `amp` を沈める(サイドチェイン風) | L004 L005 |
| Melody | 印象・歌いやすさ | 音域 1オクターブ前後、コードトーンを強拍に、導音(E → F)で解決を呼ぶ。1音を伸ばして `note_slide: 0.2` で前の音から滑らせると、「引く」感じ | L008 |
| Piano | 背後から支える | 低音域(F2〜G3)、`lpf` の `cutoff` 90 前後、`vel` 0.35〜0.4・`hard` 0.2。トップノートから音を増やして旋律に昇格 | L012 L013 |
| ビブラフォン風 | 硬く小さい金属音 | `pretty_bell` + `tremolo`(phase 0.5 拍 ≒ 4.8Hz)。`sustain` 0.25・リバーブ mix 0.12 で硬く | L014 |
| Clap / Perc | 重み・伸び | `cnoise` の3連バースト(間隔 約 12ms)+ `pnoise` の胴鳴り(約 650Hz 以下)+ リバーブ。中心を 1.2kHz に下げて高域を弱める | L015 |
| Vocal(ボコーダー) | 機械的に歌う声 | NEUTRINO の歌声 → 調声 → DSP ボコーダー。母音(う・あ)の形(フォルマント)を鋸波に載せる。滑らかさは `--smooth`・`--glide-ms`、シャリつきは `--hf-boost` | L017 |
| ハモリ | 厚み・明るさ | 主旋律の3度下(厚み)・3度上(明るさ)。コードトーンから選ぶ。上は小さめ(例 0.55) | L018 |

## 展開・構成別
| 場面 | 聞こえ方 | 裏付ける技術(数値) | 学習ログ |
|---|---|---|---|
| コード進行(区間ごと) | 場面転換・緊張と解決 | ローマ数字で設計(静: i–VI / 緊張: iv–VI–VII–V7 / 開放: i–VI–III–VII / 浮遊: III–VII–iv–V7 / 締め: i–VI–iv–V7)。V7 の導音が主和音への解決を呼ぶ | L007 |
| ビルドアップ | 期待・加速 | riser(ノイズの hpf `cutoff` 50 → 125、saw の音程 F3 → F5)、スネアロール 8分 → 16分 → 32分、4つ打ち、`amp` を少しずつ上げる | L010 |
| ドロップ前の無音 | 落差・衝撃 | 直前の1拍を無音に(キック・ハット・riser を止める)。音を引くと次の音が大きく聞こえる | L011 |
| 刻み・シンコペーション | ノリ・抑揚 | 拍の頭を外した位置(例 3-3-2 = 0,3,6,10,13)、アクセントを 0.7〜1.0 で変える | L006 L019 |
| 全員で刻む(tutti) | 盛り上がり | 複数のパートが同じリズムで一斉に。ドロップの8小節ごとの最後の2小節 | L019 |
| オクターブ重ね | 太さ・きらびやかさ | 下(-12)で太く、上(+12)で明るく。左右に振る(pan ±0.35)。必要な小節だけ | L009 |
| 区間の管理 | 構成を1か所で変えられる | `on_air(bar, 範囲)` と小節の表(`prog[小節]`)、`plan` で構成を切り替え | L020 |

## ミックス・音量
| 観点 | 目安・裏付ける技術 | 学習ログ |
|---|---|---|
| 重なっても聞き分けられる | 音域の住み分け(ベース F1〜E2 / ピアノ F2〜G3 / ワブル F4〜 / 声 F4〜Bb4)、`amp` バランス、`pan` | L012 |
| 帯域のぶつかり(マスキング) | 被る帯域を EQ で削る(例: ワブルの 1.5kHz を `mid: -0.2`、2.6kHz 以上を `high_shelf: -0.3` で、中高域 30% → 22%) | L016 |
| EQ の値 | 0.1 前後から。低域ブースト 0.25〜0.3 は RMS +5.5 dB で強すぎた(ピーク -0.1 dBFS)。数秒の試験録音で数値を比べて決める | L016 |
| 音量のゲイン管理 | 合算ピークに余裕を残す(目安 < -1 dBFS。完成版は -0.1 dBFS で余裕が少なかった)。ドロップは倍率(`drop_gain`)で一括調整。短い音は同じ `amp` でもピークが低い | L021 |
| 左右の広がり | 左右の相関(`wav_stats.py`)。1 に近いほどモノラル寄り。低音は中央、上物を左右に | L009 |

累積では「前のステムとのかみ合わせ」(ベースとキック、コードとメロの音のぶつかり、声とワブルの帯域の被り)も説明する。
