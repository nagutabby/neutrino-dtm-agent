# 技術解説の辞書(提示時に参照して数値を添える)

| トラック | 聞こえ方 | 裏付ける技術(数値は `explain_midi.py` で取る) |
|---|---|---|
| Drums | 勢い・ノリ | キック1・3拍/スネア2・4拍(バックビート)、ハイハット8分、ベロシティ(表拍強/裏拍弱)、スウィング量 |
| Bass | 土台・安定 | コードのルートを C1〜C3 に、キックと同位置(「キックと同時」割合)、音を短く切るとタイト |
| Chords | 明るさ/切なさ・広がり | 長調/短調、転回形で滑らかに、C3〜C5 の中域でベースと分離、ロングトーン=パッド的/分散=軽やか |
| Melody/Vocal | 歌いやすさ・印象 | 音域 1オクターブ前後、強拍にコード構成音、1音1音節、休符で息継ぎ、StyleShift で表情 |
| ミックス | 重なっても聞き分けられる | 音域の住み分け、音量バランス、パン、ベロシティ調整、ラウドネス(loudnorm) |

累積ミックスでは「前のトラックとのかみ合わせ」(ベースとキックの同期、コードとメロの音のぶつかり)も説明する。
