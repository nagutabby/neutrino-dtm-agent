# 技術解説の辞書(提案に数値を添えるときに参照)

| ステム | 聞こえ方 | 裏付ける技術(数値) |
|---|---|---|
| Drums | 勢い・ノリ | キック1・3拍/スネア2・4拍、ハイハット8分、`amp` の表拍強/裏拍弱 |
| Bass | 土台・安定 | コードのルートを C1〜C3、キックと同じ拍、`release` を短くするとタイト |
| Chords | 明るさ/切なさ・広がり | 長調/短調、C3〜C5 の中域、長い `release`=パッド的/短い=軽やか |
| Melody | 印象・歌いやすさ | 音域 1オクターブ前後、強拍にコードトーン、休符で間 |
| ミックス | 重なっても聞き分けられる | 音域の住み分け、`amp` バランス、`pan`、合算ピーク < -1 dBFS(`wav_stats.py`) |

累積では「前のステムとのかみ合わせ」(ベースとキック、コードとメロの音のぶつかり)も説明する。理論の根拠は `docs/music-theory.md`、技法は `docs/live-coding.md`。
