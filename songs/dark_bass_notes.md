# Dark Bass の制作メモ

スタイル: ②AIが書く(AI が Sonic Pi のコードを書き、ユーザーが聴いて方向・採否を決めた)
ジャンル: Dark Bass(低域が主役のハーフタイム系ベースミュージック。Future Bass ではない) / BPM135 / F ナチュラルマイナー / 約121秒
経緯: Dark Future Bass(`dark_future_bass.rb`、BPM130)として作ったあと、「Future Bass っぽくない」と指摘され、chiptune を外して低音管楽器と pluck に差し替え、`dark_bass.rb` として仕上げた。Future Bass の定番(幅広いスーパーソーのコード、動くボーカルのメロディ、明るい高域)は入れていない

## 誰が何を決めたか
- ユーザー: ジャンル・技法・BPM・各セクションの進行/楽器/つなぎ・音色や音量の方向・採否(聴いて決めた)
- AI: コード(Sonic Pi)、音色の具体値、数値と理論の説明。進行・構成を AI が決めた箇所は、理由を示して確認した
- 公開するとき: 「曲の雰囲気・構成・楽器・音量や音色の判断は制作者、Sonic Pi のコードの記述は AI(Claude)」のように実態に合わせて書く

## 構成(68小節 = 272拍 ≒ 121秒)
| セクション | 小節 | 内容 |
|---|---|---|
| イントロ | 1-8 | Pad のみ。拍を一部無音に |
| ビルド | 9-16 | Pad + キック + リードシンセ(dsaw)のメロディ + 低いタム。最後に曲全体をチョップ + glitch |
| ドロップA | 17-32 | キック・スネア・bass・sub・Pad・低音ピアノ・supersaw コード(前半)・**低音管楽器のスタッカート**・**1オクターブ上の pad**・**9度つきの pluck**・ハイハット・ボコーダー声の16分チョップ。進行 Fm7→Dbmaj7→Abmaj7→Bb(借用 IV) |
| ビルドアップ | 33-44 | 2小節ごとに stem を増やす(Pad → ピアノ → **7th の pluck** → キック → ハット+bass+sub → スネア+タム)。ライザーは7小節目から。最後の6拍はチョップ + glitch |
| ドロップB | 45-60 | ドロップAの楽器に低いタムのゴースト + glitch。後半8小節は Fm7→Bbm7→Dbmaj7→Ebmaj7 |
| アウトロ | 61-68 | Pad のみ。ロングリバーブで消える |

## 主な設定(v1)
- 低音管楽器: `dsaw`(cutoff 82・detune 0.08)、`gate 0.4`、bass の1オクターブ上。12 マス目 = 5度上、14 マス目 = 1オクターブ上
- リードシンセ(ドロップ): `dsaw` のパワーコード(音の5度下)+ 1オクターブ下の単音(0.1拍遅れ)、`amp 0.3`。音階 Eb 〜 の walk: C5 → Db5 → F5 → Eb5 → G5 → Eb5 → C5 → Bb4(1周8音。ドロップBは4周)
- pad: ドロップは `cutoff 100`・`amp 0.3`、1オクターブ上は `amp 0.22`。ビルドアップの pad も `amp 0.3`
- pluck: 7th(ビルドアップ)/ 7th + 9度(ドロップ)。`high_shelf -0.7`(note 84)で高音域を削る。`amp 0.3`
- 声: NEUTRINO(MERROW)→ 調声 → ボコーダー(135 BPM で作成)。wav は利用許諾により配布しない。作り直しは `dark_bass.rb` の先頭に手順
