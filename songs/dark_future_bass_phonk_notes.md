# Dark Future Bass x Phonk の制作メモ

スタイル: ②AIが書く(AI が Sonic Pi のコードを書き、ユーザーが聴いて方向・採否を決めた)
ジャンル: Future Bass + Phonk / Eb マイナー / BPM 140 / 64小節 ≒ 115秒
つなぎ: 借用和音 / セカンダリードミナント / 7th・9thの共通音保持 / ペダルポイント

## 誰が何を決めたか
- ユーザー: ジャンル・技法・BPM・キー、ステムを1つずつ足す順序、各ステムの方向(音色・音量・EQ・歪み・リズム)、採否、セクションの並び、「ライザーを使わず静寂でドロップ前を表現」「vox・pad・メロディを外す」などの判断
- AI: Sonic Pi のコード、音の高さ・リズムの具体案、数値と理論の説明。構成表の ✔ は、ユーザーの「すべて進めて」(2026-10-17)を了承として付けた(個別に聴いて了承した行ではない)
- 公開するとき: 「曲の方向・音色・構成・採否の判断は制作者、Sonic Pi のコードの記述は AI(Claude)」のように実態に合わせて書く

## 構成(64小節 = 256拍 ≒ 115秒)
| セクション | 小節 | 進行 | 鳴らす音 |
|---|---|---|---|
| イントロ | 1-8 | Ebm9→Ebm9→Cbmaj7→Cbmaj7 | 土台: ハット・808ベース(サブ) / 上モノ: スタブ |
| ビルド | 9-14 | Abm7→Cbmaj7→Dbmaj7→Bb7 | キック・スネア・ハット(8分→16分)・ベース・ピアノ(下)・逆再生キック・スタブ |
| ドロップ前の静寂 | 15-16 | 無音 | 逆再生キックだけ |
| ドロップ | 17-32 | Ebm9→Cbmaj7→Abm7→Bb7 | 土台: キック3層・スネア・ハット・808ベース(5度の跳ね+歪み)・ピアノ(下)・パワーコード(Eb ペダル)/ 上モノ: スタブ・Eb7・glitch・ピアノ(上)。4・8小節ごとの終わりで全部止める |
| ブレイク | 33-40 | Gbmaj7→Dbmaj7→Ebm9→Cbmaj7 | ピアノ(下)・ベース・スタブ・ピアノ(上) |
| ドロップ | 41-56 | ドロップ1と同じ | 同じ |
| アウトロ | 57-64 | Ebm9→Ebm9→Cbmaj7→Cbmaj7 | ハット・ピアノ(下)・ベース・スタブ |

## 主な仕組み(コードの読み方)
- `grid_gate`: 各ステムの `live_loop` が自分の小節数を `tick` で数え、`grid_song_base`(土台)・`grid_song_top`(上モノ)に載っているセクションでだけ鳴らす
- 疑似サイドチェイン: `with_fx :level` の `amp` をキックの位置で下げて戻す(`sc_depth` 0.3・`sc_rel` 0.35 拍)
- 止める処理: ドロップの 4小節ごと 0.5 拍、8小節ごと 1 拍、master の `amp` を 0 にする(逆再生キックだけ外)
- ピアノのリフ: 4フレーズ × 4小節 = 16小節ループ(A → A' → B → C)。音は根音 +0・+7・+12・+19 半音
- 先読み: `set_sched_ahead_time! 1`(ループが多いと `thread got too far behind time` になるため)

## 測った値(録音 `song_final`)
長さ 114.8 秒 / ピーク -4.2 dBFS / RMS -18.5 dBFS / 左右の相関 0.99 / 帯域: 200Hz 未満 96%・200〜800Hz 3%・0.8〜4kHz 1%
ドロップの RMS 約 -16.5、イントロ約 -23(ベースを重ねる前は約 -34)、ブレイク約 -22、アウトロ約 -22

## 未対応・未確認
- 聴感はすべて未確認(エージェントは聴けない)。低域に偏り、高域が少ない(0.8kHz 以上が 1%)
- ステレオがほぼモノ(相関 0.99)。ドロップ2回目が1回目と同じ
- アウトロはフェードアウトせず、64小節で止まる
- 未実装の技法: ピッチベンド・リード、ローファイ劣化、リバースシンバル、フォルマントシフト、ボーカルチョップ(vox は外した)
- カウンターメロディ(`blade`)は pad のように聞こえるため外した。コードは残してある
